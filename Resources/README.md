# App icon

`Stagehand.svg` is the editable app icon source. The app icon uses three skewed white window segments on a solid black background. `Stagehand.png` and `Stagehand.icns` are its raster assets.

`StagehandMenuBar.svg` contains the same white mark on a transparent canvas. The app loads it directly as a macOS template image so it follows the current menu bar appearance.
